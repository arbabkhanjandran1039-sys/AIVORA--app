# AIVORA - AI ASSISTANT by Arbab

**AIVORA - Ask anything. Discover everything.**

A clean, fast, and offline-ready AI Assistant made in Lahore by Arbab. ChatGPT-like smooth UI with WhatsApp-style bubbles.

### ✨ Features
- **Logo:** Colorful AIVORA Logo | **Splash:** Simple A (2-3 sec)
- **Welcome Card:** Ask anything. Discover everything.
- Asks user name once, saves it & always calls by name
- Remembers old chats (Local Storage)
- Voice typing 🎤, File sharing 📎, WhatsApp bubbles
- Delete Chat, Share App, Install as App (PWA - No Browser Needed)
- 100% Safe - No illegal/hack/bomb/nasha content
- **FREE AI - No API Key - Pollinations AI**
- Ad-ready for earning
- Offline support via Service Worker
